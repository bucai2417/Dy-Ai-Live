# 钓鱼玩法与滚动公告

钓鱼画面使用 Python / PySide6 原生绘制，沿用工作台的横竖屏、音乐播放器、礼物榜与 Token 显示。原生输出无需浏览器；底部玩法公告也会出现在 OBS 接收的画面中。

## 观众怎么玩

| 弹幕或操作 | 效果 |
| --- | --- |
| 钓鱼、去钓鱼、开始钓鱼、一起钓鱼 | 进入云汐钓台，人物坐在高台上持竿 |
| 切换钓鱼界面、进入钓鱼界面 | 管理员或授权今日榜单前三进入常驻钓台；重复发送仍保持进入 |
| 退出钓鱼界面、退出常驻钓鱼模式、关闭常驻钓鱼 | 同样需要权限；关闭常驻并收竿返回，保存设置后重启仍生效 |
| 拉、拉钩、拉勾、提竿、收线 | 咬钩后协力拉鱼，每条独立弹幕都有效 |
| 点赞 | 咬钩后推进收线，默认 10 赞等效一次拉钩 |
| 任意礼物 | 咬钩时每件默认等效5次拉钩；常驻非咬钩时触发礼物专属撒网 |
| 换个钓点 / 换个地方钓鱼 | 等待阶段收竿提桶，沿栈道去下一个钓点，约10秒后重抛；当前鱼、礼物和榜单安全时才执行 |
| 去芦苇浅湾 / 去星礁海岸 / 回云汐钓台 | 直接前往指定钓点；芦苇湾偏小型水族，星礁海岸偏海洋水族 |
| 松、松线、放线、放松鱼线 | 咬钩时默认减少8个百分点进度，最低0；全场间隔2秒，不增加捣蛋者贡献 |
| 投饵、喂鱼、撒鱼饵 | 等待时播放投饵、鱼群聚拢，剩余等待缩短35%，最低保留3秒；全场间隔12秒 |
| 加油、护线、钓鱼加油 | 咬钩时举手加油，基础脱钩概率减半10秒；全场间隔10秒 |
| 跳水、花式跳水、下水游泳 | 放竿、到台边、随机跳水、水花、游2～4圈惊散鱼群、跳回台上重新抛竿，约24秒 |
| 收竿、不钓了、结束钓鱼、退出钓鱼 | 提前结束，返回原场景 |
| 换个场景、回家、出门等已有场景指令 | 普通模式结束钓鱼；常驻模式临时执行约20秒，随后回到钓鱼台继续本轮 |

开局后默认随机等待12～28秒咬钩，咬钩后每竿随机获得25～45秒的溜鱼时限，提前拉满即可捕获。最短与最长时长都能在设置中调整。水中同时最多12条背景鱼，水族种类扩到44种，包括鲸鱼、虎鲸、鲨鱼、双髻鲨、龙虾、帝王蟹、海龟、蝠鲼、章鱼、水母、海马等，各有外形、体型、重量与图鉴分数；大鱼需要更多拉钩。普通拉钩默认6%脱钩概率，点赞按等效拉钩次数计算风险；礼物助力单次风险为普通拉钩的四分之一，连送数量不会倍增风险。

**贡献归属**：按“拉钩次数 + 实名点赞数 ÷ 每次拉钩所需点赞数 + 礼物数量 × 礼物拉钩力度”累计鱼竿贡献，最高者获得本条鱼，同分先参与优先。默认10赞相当于1次拉钩，每件礼物相当于5次拉钩。常驻非咬钩礼物改为撒网，撒网收获全部归送礼者。非专用直播、关闭撒网或撒网队列满时，未咬钩礼物仍存为下一次咬钩助力。礼物演出或临时互动冻结了已上钩的鱼时，新礼物仍用于这条鱼的强力拉钩。聊天拉钩和点赞仅在收线阶段生效；松线不改既有贡献。手动拉钩不抢观众归属，匿名点赞只推进全场进度。

成功后先播放鱼跃出水动画，再显示至少 6 秒庆祝界面：贡献冠军名称、鱼的品种、原生绘制插画、稀有度、重量和图鉴价值。图鉴价值是玩法分数。普通模式随后回到开局前场景；脱钩或超时显示至少 4 秒提示后返回。结果语音尚未结束时适当延长结果展示，最多 30 秒；常驻模式随后自动续竿。

同样文字可以连续发送，每条独立消息都会推进；只有采集通道重发同一条消息 ID 时才去重，避免一次操作被重复计算。抖音协议点赞使用每条消息中的新增点赞数，房间累计总赞数不变、为零或回退时也不会丢掉新的点赞。只有累计值的补采事件仍先计算差值，不把接入前的历史总赞一次性用于拉鱼。

最近4096条协议点赞ID随当天统计保存，防止断线重传或同日重启后重复计算。收线阶段显示一位小数百分比；等待咬钩、结果展示、跳水、撒网或暂停期间的点赞不增加收线进度。“松”等新动作有明确冷却提示，内容相同的新消息仍可在冷却结束后触发。

## 礼物撒网与自动昼夜

默认常驻时开启撒网。等待咬钩收到礼物后，人物放下鱼竿、蓄力、挥臂抛网、沉网，再双手收网，约10秒；之后展示至少8秒实名庆祝卡和鱼获插画，语音未读完时最多延长到30秒。撒网结束继续原鱼竿，保留原等待时长。跳水、结果展示或其它演出期间的礼物会排队，回到等待阶段再撒网。

一网总图鉴分 = 接入源提供的本次礼物总价值 × 设置倍率 × 随机0.8～1.4，取整且至少1分。默认倍率20，价值不是人民币。例：本次礼物总价值100，默认一网1600～2800图鉴分；礼物数量不再重复乘一次。1～5条鱼分摊这笔总分，礼物越大通常鱼越多、种类越珍贵；这些是不可兑换的玩法积分。输入价值安全上限100万单位，合并待播礼物也受此上限约束。

抖音协议接入优先读取礼物实际单价和新增连送数量；同一组连送的结束通知、累计值回退不会重复发奖。DOM接入或缺失可靠价格时按礼物数量估算，庆祝卡明确显示“未提供价值，按礼物数量估算”。桥接的giftValue/price维持单件价格约定，先乘数量形成统一事件总价值。

每位送礼者有独立归属，同一用户尚未开始的礼物合并成一网；最多32位排队，满队列的新用户走原礼物演出和助力，避免无限堆积。撒网代替本次普通礼物演出，墨镜装扮仍会保留；咬钩时仍播放原专属礼物演出并强力拉钩。收网成功后只结算一次，今日榜和图鉴都保存。正在撒网及排队状态仅在内存中，关闭玩法、退出常驻或重启会清除未完成的一网与队列；已完成鱼获保留。

昼夜默认600秒一轮，平滑切换晨曦、白昼、暮色、夜钓；夜里出现星月、岸灯与水面反光。设置可改为120～7200秒一轮、跟随电脑当地时间、固定白天或夜晚。自动循环跨鱼竿持续，暂停时冻结；背景缓存复用，原生绘制不启动浏览器。

## 常驻自动互动与换钓点

常驻模式增加独立的冷场调度器。等待咬钩且没有礼物、点赞整活、语音或其它活动时，默认安静25秒后随机播放一个5～7秒的小动作：遮眼观察、持竿伸懒腰、沿钓台挪位、低头检查鱼线。动作不会改变咬钩倒计时、不会自动拉钩、不会增加点赞，也不会伪造观众或鱼获。真实弹幕、礼物、关注和新增点赞会立即清空冷场动作并重新计时；相同消息ID重传不会被当成新的互动。

安静约90秒后，AI语音会介绍当前钓点并邀请观众发“投饵”“跳水”或“换个钓点”，每次邀请有冷却，语音可以在设置关闭。语音与礼物、咬钩提醒、暂停和用户正在说话时互相避让，避免叠音。

默认连续180秒没有成功收获，或者连续3竿失败，会在**等待阶段且距离咬钩至少4秒**时自动换点。正在咬钩、收线、撒网、跳水、结果展示、礼物排队或刚收到真实互动时不会突然切走；换点本身约10秒，显示收竿、提桶、沿栈道移动，到新位置后重新抛竿。换点不会自动宣称“已经钓到鱼”，失败计数在成功收获或抵达新点后重置。

自动钓点包括：

- **云汐钓台**：开阔云湖，鱼群均衡。
- **芦苇浅湾**：芦苇、荷叶和浅水，小型水族概率提高。
- **星礁海岸**：礁石和灯塔，鲨鱼、金枪鱼、龙虾、蝠鲼等海洋水族概率提高。

主播可发送“换个钓点”“去芦苇浅湾”“去星礁海岸”“回云汐钓台”，也可以使用场景导演按钮。指定钓点与自动换点都不会退出常驻模式。关闭自动小动作、自动换点或主动邀请后，常驻基础钓鱼仍可使用。

程序根据当前阶段、计时、互动和礼物状态决定是否播放动作或换点，优先响应观众的操作。这些功能用于丰富直播内容，不能保证平台审核结果或避免封禁。

## 今日鱼获排行榜

钓鱼时信息栏显示“今日钓鱼榜 · 总价值”，按成功鱼获的价值累加，同分先上榜优先。鱼竿收获归本轮贡献冠军，撒网鱼获全部归对应送礼者。横屏前五名、竖屏前三名，后台保存当天全部记录。

开始、咬钩和拉钩都不提前计分，进入捕获成功阶段才结算一次。脱钩、超时和未捕获时收竿不加分；重复状态广播、断线重连不会重复加分。完全依靠匿名汇总点赞或主播手动拉钩的捕获记入“全场协力”，不冒充某位观众上榜。能识别用户的点赞参与个人贡献排名。

成绩随今日数据自动写入 data/live-stats.sqlite3，通常一秒内保存，正常关闭后台时再保存一次；同一天重启和清空本场弹幕不会清除鱼获榜。跨天从新的今日榜开始，原日数据保留在数据库中。按用户 ID 区分同名用户，没有 ID 时按昵称合并。

AI 会收到真实的榜首信息、累计价值、捕获数量和玩法规则，回答排行榜问题时以当前记录为准。

常驻钓鱼水面底部展示“今日水族 / 奇物”：统计实际咬钩及成功撒网捕获的种类与数量，含脱钩，不统计背景游鱼。每页2种、6秒轮播，随今日数据保存，跨天重新统计。

## 管理员与榜单权限

默认允许平台管理员，以及今日钓鱼价值榜或礼物价值榜任一前三名切换常驻界面。“设置 → 钓鱼玩法”可关闭弹幕切换，或改为仅钓鱼榜、仅礼物价值榜、仅管理员。按执行时的当天排行重新检查，名次跌出前三或跨天后旧权限不保留；同分按榜单已有顺序。

管理员来自接入通道提供的明确管理员标记，也可填写额外管理员用户ID，每行一个。榜单权限严格按用户ID匹配，昵称相同、自称管理员、缺少ID均不能取得榜单权限。DOM采集没有可靠的管理员字段，需使用能提供身份字段的协议接入或用户ID白名单。

普通“钓鱼”仍开启单局；“不钓了”不能关闭常驻，会提示使用“退出常驻钓鱼”。支持退出/关闭/结束/停止常驻钓鱼模式等明确指令，身份限制相同。主播可直接点场景导演的“退出常驻钓台”，或在设置关闭“钓鱼专用直播”。退出保存配置，重启不会自动重入。普通礼物演出会继续播完，钓鱼及尚未完成的撒网会取消。

## 趣味奇物与紧凑文字

共有44种水族、12件奇物。新增白鲸、独角鲸、鲸鲨、鮟鱇、比目鱼、飞鱼、鹦鹉螺等；奇物包括海水过滤器、鳗鱼过滤器、宝藏箱、雨靴、漂流瓶、潜水头盔、珍珠贝、罗盘、小黄鸭、烧水壶、吸铁石、扫地机器人。每种均有独立原生插画、重量、价值和打捞难度。

默认18%的上钩机会抽中奇物，再按奇物内部权重抽取；可在钓鱼设置中调整为0～50%。奇物不会作为背景游鱼游动。过滤器是趣味收藏道具，不提供实际过滤功能。成功后展示专属插画、趣味说明并按价值计入贡献冠军的今日钓鱼榜；礼物、拉钩和点赞规则与水族一致。AI知道奇物状态，打捞、催拉、滑落等台词可在内置话术中编辑。

钓台标题、图鉴和状态使用缓存描边文字，移除大片不透明背景；庆祝仅显示较小的半透明卡片，不再将整个场景压暗。字幕最多两行、长文本分页保留全部内容；在钓鱼设置可调整14～26字号及可选轻薄底色，默认无底板。横竖屏字幕均避开收线进度与图鉴。

## 工作台与设置

“场景导演”提供 **去钓鱼 / 协力拉钩 / 花式跳水 / 收竿返回** 按钮，可在开播前直接试玩。

“设置 → 钓鱼玩法”可以调整：

- 启用协力钓鱼。
- 钓鱼专用直播：保存后常驻钓台，成功、脱钩、超时后自动续竿。跳舞、倒立、短片、点赞整活和场景互动可以临时中断，结束后继续原竿；换装直接保留。永久退出可由管理员或授权榜单前三发送“退出钓鱼界面”，也可在设置关闭。
- 钓鱼互动语音：下竿、咬钩、再次催拉、捕获与脱钩播报。台词在“内置话术 → 钓鱼”分类修改，咬钩提醒不等待在线模型。
- 多少赞相当于拉一次钩：1～10000，默认 10。
- 每次拉钩脱钩概率：0～0.5，默认 0.06；设置为 0 可进行必不脱钩的演示。
- 等待咬钩最短/最长时间：默认12/28秒；溜鱼最短/最长时限：默认25/45秒；均可设3～300秒，最短不能大于最长。新时长从下一阶段开始采用。
- 每件礼物拉钩力度：2～30次，默认5次。
- 常驻自动小动作：默认开启，等待25秒后播放；可调整安静时间。
- 久无收获自动换点：默认开启，180秒无成功或3竿失败触发；只在安全等待阶段执行。
- 常驻冷场主动邀请：默认开启，90秒间隔；AI会根据当前钓点和状态邀请观众操作。
- 自动普通场景巡游：默认开启，普通场景90秒无人互动后散步；观众一出现就停止，睡觉、开车、场景行为和钓鱼不会被抢占。
- 昼夜模式及循环周期：默认自动600秒一轮，可固定昼夜或跟随当地时间。
- 常驻撒网开关及积分倍率：默认开启、每价值单位20分，倍率范围1～1000。
- 松线开关及减少比例：默认开启、每次8个百分点，可调1～25个百分点。投饵和加油直接用弹幕或场景导演按钮。

保存后立即生效。关闭钓鱼玩法或全局互动开关会结束正在进行的钓鱼，并回到原场景。

## 暂停、重连与其他互动

钓鱼期间冻结原场景的位置和行为时钟，结束后恢复。常驻动作、视频和整活会临时放竿，保留当前鱼时限与进度；场景互动约20秒，长途移动预留到达时间。跳水会放走当前鱼，人物随机翻腾、入水、游2～4圈并回台重抛；期间礼物按撒网或原助力规则排队。撒网时发送跳水、跳舞会提示等待，需要演出完成后重新发送；所有水花和鱼群运动由原生画布绘制。

暂停直播会冻结咬钩、收线和庆祝倒计时，恢复后接着进行。后台持续运行时，原生窗口断线重连会重新获取本局阶段、鱼种、进度和贡献榜。正在进行的钓鱼回合保存在后台内存中，重启后台后不会继续上一竿，常驻模式会自动开启新的一竿。礼物演出期间也冻结本局，演出完恢复。

AI 状态上下文包含常驻模式、当前阶段、收线进度、剩余时间、贡献者、捕获结果和冠军。明确的钓鱼口令直接执行，无需等待在线 AI；人物沿用现有鱼尾骨架、服装、配饰和语音口型。

## 滚动公告（跑马灯）

进入“设置 → 滚动公告”，填写玩法介绍，调整 **显示开关、文本内容、滚动速度** 后保存。文本最多 2000 字，多行内容会合并成带分隔符的一条公告，从右向左循环滚动。

速度范围为 5～240 设计像素 / 秒，默认 55；数值越大移动越快。公告位于直播画面底部，横屏和竖屏均预留位置。空文本或关闭开关会隐藏公告，暂停直播时滚动也暂停。

可以直接填入：

> 发“去钓鱼”开启协力钓鱼，咬钩后点赞或发“拉钩”收线 · 换个场景 / 回家 / 点歌 / 换装，弹幕一起玩！

## 主动介绍玩法

“设置 → 冷场互动”增加“主动邀请观众体验已开启的玩法”及最短间隔，默认开启，间隔 180 秒。达到“语音与节奏”中的冷场等待时间后，优先邀请钓鱼，再轮换介绍场景、换装、整活和点歌。例如：“有点想去钓鱼了，你可以发钓鱼。咬钩后发拉钩，点赞也能帮我收线。”

在线 AI 会根据真实能力与当前状态组织措辞；离线时使用完整内置话术。“设置 → 内置话术”中的“玩法邀请 · 钓鱼”等分类可直接编辑。关闭的功能不会被主动推荐；正在钓鱼、执行动作、播报或暂停时不插入邀请。默认音乐播放时也暂缓，可通过已有开关允许音乐期间聊天。邀请只介绍口令，不会未经观众指令自行开始钓鱼。

## 开发验收

在项目根目录顺序执行：

~~~powershell
$env:PYTHONUTF8='1'
python -m pytest tests/test_fishing.py -q
python tools/check_fishing.py
python tools/check_fishing_native.py
python -m pytest tests/test_fishing_expansion.py -q
python tools/check_fishing_expansion.py
~~~

离线绘图检查在 logs/fishing-check 输出水族图、横竖屏各阶段截图及绘制耗时。扩展验收在 logs/fishing-expansion-check 输出完整水族与奇物图鉴、两种过滤器庆祝卡、轻量字幕、跳水连续阶段截图、最小化帧率、礼物冠军、管理员与榜单权限及今日图鉴落盘报告；加 --screens-only 可只绘制截图。

原生检查使用临时配置、独立端口、关闭的弹幕采集与离线 AI / 语音，不修改真实直播设置和当日统计。它验证弹幕触发、重复拉钩、贡献归属、点赞钓获、暂停、断线重连、自动返回与公告保存；专用直播和礼物检查见“礼物演出与直播陪伴”。
