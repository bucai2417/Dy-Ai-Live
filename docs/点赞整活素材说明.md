# 点赞达标整活

默认每新增 100 赞触发一次，轮流播放「深蓝环游 · 流光泡泡」「鱼鱼骑车巡游」「蛛丝空中摆荡」「鱼鱼火箭升空」。在原生工作台「直播设置 → 点赞整活」可修改点赞数量、轮播 / 随机 / 固定动作、动画间隔和进度条显示开关；「直播控制」页提供预览整活与测试点赞 +10。手动预览不修改真实累计点赞数。

自动整活同时受「点赞达标整活」与「自动响应弹幕 / 礼物动作」控制。四段动画分别约 16 秒、8 秒、9 秒、7.5 秒，默认间隔 5 秒。只统计本次接入后收到的点赞；页面首次累计值作为基线，不因之前已有大量点赞而补播。界面显示本次收到数量与下一目标，和平台整场累计数可能不同。

达到多个目标时最多等待三段动画，额外目标合并到最后一段并标注「连达 N 档」，累计点赞数不会扣掉。直播暂停冻结当前动画及等待队列，暂停期间的点赞只计总数、不推进整活进度；恢复后从暂停处继续。关闭自动整活会清理自动动画；修改阈值会清理待播并从当前总数建立新目标。清空本场或重启服务归零；切换房间或接入源也重新计数。单纯画面断线重连会读取当前动画已播放时间，避免从头重复播放。

## 动画实现

- 环游：16 秒舞台巡游、平滑转向、远近变化、双臂划水、鲸尾摆动、流光尾迹和泡泡；兼容换装、口型和叠加互动。
- 骑车：人物上半身贴图、原生车架、旋转车轮、鱼尾踩踏杆、路面移动和人物摇摆。
- 蛛丝：向上伸长的丝线、顶部附着点、抬手牵引、弧线摆荡和速度线。
- 火箭：火箭外壳、动态火焰、烟雾、人物上升和轻微横摆。

使用现有 Deepy 立绘和眼嘴贴片，保留装扮、眨眼和语音口型，未新增浏览器或逐帧网络请求。渲染在独立线程运行，动画时间使用单调时钟；后端最多每 0.25 秒推送发生变化的点赞状态，显示端逐帧插值。横竖屏都在人物区域内裁剪动画，不遮住 Token、播放器或聊天室。动画期间将礼物头像气泡淡化，结束自动恢复。

当前使用二维分层骨架与程序道具，手臂和尾部通过独立关节活动；不是三维角色模型。原人物是鱼尾形象，骑车采用鱼尾驱动的趣味表现。新增三维布景和天气、镜头控制见 [三维场景与点赞环游](三维场景与点赞环游.md)。

## 后续生图素材规格

本次读取了 imagegen 技能，但当前会话没有可调用的内置 image_gen 工具，未执行生图，也没有调用 CLI 图像 API。以下提示词用于后续工具可用时生成替换素材，不代表已有生成结果。技能的 CLI 备选方案需要 OPENAI_API_KEY，并需用户明确选择该方案。

参考图：web/assets/whale/art/deepy.png，仅作为人物身份、色彩和画风参考。最终项目素材建议放在 web/assets/whale/art/stunts/，生成成功后先检查透明通道、人物一致性和分层边界再接入；目前动画没有引用此目录，不会因缺图而报错。

### 骑车人物透明素材提示词

用途：原生直播互动的二维人物精灵。以参考图中的蓝发鱼尾女孩 Deepy 为唯一角色，保持脸型、发色、眼睛、水滴发饰、蓝白水手服和鱼尾。生成一个向右略侧身、上身前倾、双手握把的骑车姿势，表情快乐，鱼尾弯向脚踏位置。仅人物，无自行车、无路面、无文字、无阴影背景，完整边缘、真实透明背景。保持原图细腻的二次元插画画风，适合以约 230 像素高显示。不得添加蜘蛛侠服装或改变人物身份。

### 蛛丝摆荡人物透明素材提示词

用途：原生直播互动的二维人物精灵。参考图仅作为人物一致性参考。相同 Deepy 蓝发鱼尾角色，一只手高举握住画面上方的绳索位置，另一只手自然向侧面展开，身体略斜，鱼尾向外弯曲，开心惊讶表情。仅人物，完整包含举高的手和尾部，不绘制蛛丝、不画背景、不写字，真实透明背景。保持原有水手服与发饰，避免手指畸形，适合实时整体旋转摆动。

### 火箭道具透明素材提示词

用途：二维直播互动道具，与参考图的可爱蓝白二次元风格协调。生成一枚正面朝上的迷你青蓝火箭，圆润机身、浅蓝圆窗、金色小尾翼，留出上方人物乘坐的空间。只画火箭外壳，不包含人物、火焰、烟雾、文字或背景；完整轮廓，真实透明背景。将火焰与烟雾留给程序绘制，避免烘焙进道具导致动画僵硬。

## 验证

测试文件：tests/test_like_stunts.py。覆盖点赞增量与累计字段、重复与乱序累计值、页面到协议采集的切换、批量点赞不截断、精确目标、自动轮播和随机不连播、队列上限与合并、暂停续播、关开配置、重连同步、原生横竖屏动画边界。

运行 python -m pytest tests -q 进行全套测试；运行 python tools/check_native.py 使用隔离配置验证原生窗口，并输出 logs/native-check/点赞整活-动作-横屏.png / 竖屏.png、点赞整活设置.png 和点赞整活动画预览.gif。没有连接真实直播间、调用在线模型或收费图像接口。

2026-11-07 本机验证：全套 355 项测试通过，最后布局调整后的 24 项整活专项测试通过；3 条已有依赖弃用提示。最终原生整活运行期间最小化 4 秒绘制 120 帧，约 30 FPS，测量结束时单帧 13.58 毫秒。精确点赞目标、暂停续播、横竖屏绘制、音乐继续播放、FFmpeg 解码 60 帧和重连通过。已输出约 3.7 MB 的 96 帧 GIF 预览，GIF 为抽帧展示；实时动画按原生渲染帧率运行。

正式 runtime.json 与本轮备份逐字节一致；5 个 BAT 保持 UTF-8 无 BOM、CRLF，新增中文源码与文档均通过 UTF-8 严格解码检查。短时本机测试不替代真实抖音接入及长时间推流验证。
