# 原生直播横竖屏切换

## 使用

启动工作台后，在左侧直播预览上方点击「横屏」或「竖屏」。默认竖屏为 720×1280，横屏为 1280×720，按各自比例重新排版。已有窗口需要重新启动一次才能加载本次代码；之后切换不需要重启。

选择在新尺寸画面输出后自动保存，下次通过启动 BAT、桌面入口或不带尺寸的启动 API 打开时恢复。保存位置为 data/native-display-18849.json；使用自定义输出端口时，每个端口独立记忆。文件缺失或损坏时使用默认竖屏。服务暂时断开时也可切换，重连不会改变方向。保存失败会显示提示，本次画面仍可正常切换。

明确指定命令行 --width / --height 或启动 API 中的尺寸时，以指定值为准；只指定一边时，另一边保持原先默认值 720 / 1280。自定义尺寸切换时互换长短边，例如 1920×1080 与 1080×1920；正方形切换时使用默认横竖屏尺寸。尺寸仍限制在 320～1920，帧率设置保持原值。

「画面输出」页显示当前尺寸，已打开的纯净画面窗口也会等比调整。纯净窗口最大化或全屏时保留窗口状态并在内部等比显示。主工作台窗口保持原有大小，预览等比适应可用空间。

## 横屏排版

| 区域 | 内容 | 适配行为 |
| --- | --- | --- |
| 顶部 | 名称、直播状态、图标统计、Token 与费用、点赞目标 | 眼睛表示在线人数，气泡表示弹幕数，回箭头表示今日回应；大数自动缩写 |
| 主场景 | 房间、人物、钓鱼、透明视频、点赞整活 | 横屏场景占 952×526 设计像素，字幕按需叠加；宽视频等比缩放 |
| 右侧 | 榜单、聊天室、当前歌曲与下一首 | 钓鱼时显示今日鱼获价值前五名，其余时间为守护榜；长中文自动省略 |
| 全屏叠加 | 最多十个礼物头像气泡 | 可跨越场景和信息栏，互相碰撞，在整个画面边缘回弹 |

竖屏的场景为 688×788 设计像素，顶部同样使用紧凑统计条。榜单和聊天室并排放在场景下方，音乐压缩为底部播放器，保留当前歌曲、下一首和进度；钓鱼榜显示前三名。相较此前布局，默认开启 Token 时，竖屏场景面积约为原来的 2.19 倍、横屏约为 1.83 倍。

Token、统计、弹幕、守护榜和播放器的显示开关继续生效。钓鱼期间的鱼获榜独立于守护榜开关，保证玩法成绩可见。统计和 Token 开关不再改变场景坐标，避免切换设置时房间突然跳动。

## 连续输出与 OBS

切换在原来的渲染线程内完成，复用人物素材、头像缓存、音乐与视频控制器、互动状态和视频输出服务。礼物气泡按新的全屏范围映射位置，点赞动画不重新开始；暂停期间切换仍保持暂停，恢复后继续。快速连续点击只需绘制最新请求的尺寸，不会创建一批窗口或渲染线程。

视频源地址与端口不变，工作台预览和截图使用新尺寸。视频流仍以固定 25 FPS 发送 JPEG，原生绘制目标默认 30 FPS。切换会改变流中的帧尺寸。

OBS 的画布与场景属于 OBS 自身设置，本工作台不会代为修改。切换后请同步调整 OBS 的画布 / 输出比例，并重新把媒体源适配到画布；如果现有媒体源没有刷新尺寸，可重新激活媒体源。建议开播前先选定方向。

## 后续增加内容

app/native/layout.py 中的 StageLayout 是统一的区域定义，采用 720×1280 与 1280×720 两套设计坐标。主场景和信息栏位置在 stage_layout 中定义；实际输出像素尺寸交给 Scene 缩放。

新增投票、小游戏或任务面板时，先在 StageLayout 中分配区域，再让对应绘制函数使用该区域。effects 用于场景和短动画，subtitle 用于按需叠加字幕；bubbles 是独立的全屏范围。气泡在界面内容之后绘制，不继承场景裁切。钓鱼字幕避开收线进度条，捕获庆祝期间隐藏临时字幕。

tests/test_orientation.py 覆盖保存 / 重启、尺寸覆盖规则、布局边界、快速切换、暂停状态、连续 MJPEG 连接、保存失败与后台启动参数。tools/check_native.py 使用隔离配置和本地媒体，验证真实原生播放器、透明视频与点赞整活期间的切换，以及两种方向最小化后持续输出；截图和报告保存在 logs/native-check。
