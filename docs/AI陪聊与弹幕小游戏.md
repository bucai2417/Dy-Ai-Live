# AI陪聊与弹幕小游戏

这些功能使用已配置的文本AI与现有语音引擎。直播画面仍由Python/PySide6绘制，不打开浏览器。AI画你猜使用模型生成的矢量简笔画，不是调用外部生图接口。

## 无人互动时自主聊天

1. 在「AI模型」设置可用的接口、密钥、模型，测试连接并保存。
2. 在「冷场互动」开启「AI自主找话题聊天」。填写可选的「话题偏好」，例如“海底生活、童年趣事、轻松脑洞，少问观众问题”。这里是方向提示，不是固定台词。
3. 在「语音与节奏」设置冷场等待间隔。默认45秒，AI自主聊天至少等15秒；目标字数默认120，可设40～300，按完整句收尾。
4. 没有真实观众活动、回复、演出等占用时，AI自主挑选话题。最近12段话题及内容会作为记忆传入后续请求。

不要求在线人数大于零。没有增加点赞数的同步消息不会重置冷场等待。音乐播放时是否说话由「音乐播放期间也允许冷场聊天」控制；睡眠、驾驶、小游戏、咬钩和收获动画期间会让路。等待咬钩且仍有10秒以上时可以聊天。

模型未配置、限流、返回无效内容时等待重试，并在场景控制面板「自主聊天」中显示状态，不使用内置聊天替代。生成期间收到真实观众互动会放弃过时话题。全局TTS设为“仅显示字幕”时只显示文字。

这个模式不依赖「启用预设互动话术」，也不使用「内置话术」的冷场条目；关闭AI自主聊天后可继续使用传统模式。礼物感谢、梦话和场景动作的事件台词保留原有设置。AI自动点歌仍只从审核歌单选择，不会用预设DJ台词冒充新生成的聊天。

## 开始与控制小游戏

在「弹幕小游戏」设置中开启小游戏，人物互动也需开启；AI必须可用。场景控制面板有成语接龙、AI画你猜、下一题、结束小游戏四个按钮。

| 弹幕 | 行为 |
| --- | --- |
| 成语接龙 / 来玩成语接龙 | AI出成语题，开始本局 |
| 你画我猜 / 我画你猜 / 猜画 | AI现场生成简笔画，开始本局 |
| 四字成语 / 直接猜答案 / 我猜是…… | 按当前题目判定 |
| 结束小游戏 / 退出游戏 | 结束整局，恢复原活动 |
| 下一题 / 换道题 / 跳过这题 | 猜画公布当前答案，稍后进入下一题 |

任何观众可开局，但结束和跳题只允许主播控制台、开局者的真实用户ID、接入源管理员或设置中配置的管理员ID。昵称“管理员”无效。关掉弹幕开局不会锁死已有开局者的结束权限。

出题期间不能跳题。成语接龙不支持跳题，可结束后重新开局。暂停直播时游戏冻结，恢复后再操作。

## 成语接龙规则

AI选择一个常见四字成语并给出释义。例：心想事成 → 成千上万 → 万事如意。后一个成语的首字必须与前一个末字相同，不接受谐音。同一局用过的词不能重复。

程序先检查字数、首尾字和重复使用，再由AI核验真实性与释义。按收到答案的先后顺序处理，首位有效答对者得10分；画面显示昵称、庆祝、积分和接下来的字。其他人不会重复拿到同一回合的分。

相同文字的新弹幕仍会处理；只去除相同消息ID的重复投递。判题失败不扣分，可重新发送；队列繁忙会提示稍后重发。请求在后台异步执行，不阻塞礼物、点赞或画面。AI判定可能有误，当前没有词典级正确性保证。

## AI画你猜规则

模型自主选一个2～6字的物品、动物或自然事物，用折线、椭圆和矩形生成简笔画。画面在默认12秒内依次画出笔画，先看轮廓，再看细节。

观众直接发送答案，也可发“我猜是雨伞”。接受题目生成时提供的同义名称，忽略常见标点和空白；当前不额外用AI给每条猜测做语义判断，也没有模糊错别字匹配。答错不扣分。

在答题时长的40%和70%处展示两级提示。答题阶段的公开状态不包含答案与同义词，AI聊天上下文也不含画作答案；答对、超时或主播跳题后才揭晓。得分从30分开始，每过去5秒减少2分，最低10分。

模型只能提交经过校验的笔画、坐标和调色板颜色，不会执行模型生成的代码或加载任意图片网址。画作质量随文本模型能力变化，复杂对象可能不够像；主播可跳题。

## 时间、积分和其他玩法

默认每局最多5回合，每题60秒。可在设置调为1～10回合、30～180秒，绘画时间5～30秒。无人答对的题目结束后，整个游戏也会结束；结果停留约8秒，祝贺正在播报时可适当延长，最多30秒。

本局小榜单显示前三名，积分只属于这局，不代表钱，不写入今日钓鱼榜，重启或新开局不会保留。游戏不自动赋予礼物分数或虚构观众。

原场景、钓鱼与点赞整活在小游戏期间暂停。礼物继续正常显示专属演出，游戏倒计时冻结，期间答案可以排队；演出完继续判题。场景动作与视频请求会提示先结束游戏。常驻钓鱼只在等待咬钩时可开启游戏，结束后继续原来的鱼竿。

「安静时自动邀请玩小游戏」默认关闭，可选开启，默认300秒无真实互动后交替开局。游戏无人参与时会超时退出，不会无限续题；下一次仍需重新等待冷场间隔。

## 费用与排查

自主聊天、出题、成语核验都计入现有Token统计。猜画出题最多申请5000输出Token，成语题600、单次核验500、聊天1000，实际以接口返回用量为准；服务不返回完整用量时延用现有估算方式。

- 一直“AI未连接”：检查模型设置与限流/鉴权状态，先测试连接。
- 出题失败：模型必须能返回符合约定的JSON；不会悄悄改用固定题库。可等限流恢复或换用更擅长结构化输出的模型。
- 冷场没有说话：查看「自主聊天」状态、最近真实互动、音乐避让、当前玩法、TTS及最短等待时间。
- 游戏没有声音：检查小游戏播报开关、TTS和系统/OBS音频采集。画面不依赖语音成功。
- 开局提示等待：咬钩、收线、礼物、点赞整活或其他播报尚未结束，等活动结束后再开。
- 更新后看不到新按钮：这些改动属于main后续构建，旧的1.0.0文件不会自动改变；更新程序并完整退出后重新启动。
