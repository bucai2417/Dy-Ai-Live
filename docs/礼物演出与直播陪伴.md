# 礼物演出与直播陪伴

以下功能在 Python / PySide6 原生工作台运行，包含横竖屏输出，不需要浏览器展示画面。更新后重新启动后台和原生工作台，新设置保存后立即生效；默认关闭常驻钓鱼和 BGM，保留原来的开播方式。

## 钓鱼专用直播

在“设置 → 钓鱼玩法”开启“钓鱼专用直播”。每局捕获或脱钩后自动下新的一竿，持续停留在钓台。关掉此项返回原场景；关闭钓鱼或全局互动也会退出。直播暂停、礼物演出期间暂停游戏时钟，不会背后超时脱钩。

本轮冠军按“拉钩次数 + 实名点赞数 / 每拉所需点赞数 + 礼物数量 × 礼物力度”决定，默认10赞折算1次拉钩，每件礼物折算5次，同分先参与者优先。名字来自弹幕、点赞和礼物事件。若平台只提供房间总赞数，这部分仅帮助收线；全部匿名时显示匿名合力。未咬钩时的礼物先存助力，下一次咬钩结算。贡献冠军获得整条鱼的图鉴价值，今日榜继续持久保存。

常驻钓鱼支持跳舞、倒立、整活、短片和场景指令临时中断后续钓；发“跳水”可以放竿后表演约24秒的跳水游圈，惊走当前鱼并重新抛竿。共有44种水族和12件趣味奇物，可调随机时长及奇物概率，提供今日图鉴和轻量描边字幕。管理员或授权榜单前三可发“切换钓鱼界面 / 退出钓鱼界面”，详见《钓鱼玩法与滚动公告》。

打开“下竿 / 咬钩 / 催拉 / 收获互动语音”，会按真实游戏阶段播报。咬钩后约 9 秒仍未钓起，会再提醒一次。过期的拉钩提醒会被取消，避免鱼已经钓起还在催拉。结果播报期间可延长结果展示，最长 30 秒。语音引擎仍使用现有设置；选“仅显示字幕”时不生成声音。

## 礼物专属动作

“设置 → 礼物演出”可分别开关完整特效、感谢语音和大啤酒随机奶蛙。

| 礼物名称包含 | 演出 |
| --- | --- |
| 啤酒 | 接杯、举杯、热气、饮茶、谢幕；有效视频开启时随机选奶蛙 |
| 鲜花、玫瑰、花束、花花 | 捧起花束，左右展示、点头、谢幕 |
| 棒棒糖 | 拿起巨型旋纹棒棒糖，举高展示、挥手、谢幕 |
| 墨镜 | 接住眼镜、抬手佩戴、左右摆造型、闪光；配饰保留 |
| 爱心、心等 | 双手抱住爱心，心形跳动与光粒 |
| 火箭、飞船、飞机、飞艇 | 手持火箭，尾焰与升空动作 |
| 皇冠、王冠、城堡、嘉年华 | 星光加冕与金色庆祝 |
| 其它礼物 | 手持星光、挥手致谢与专属名片 |

每段 10～12 秒，包含接礼、展示和谢幕；道具跟随手部骨架。每一位送礼者都显示头像、昵称、礼物名和数量，不受头像气泡前十名限制。头像下载失败时使用昵称首字占位。演出期间冻结钓鱼、跑步、开车或睡眠等原活动，结束后继续原活动；普通弹幕动作不能覆盖演出。

礼物按顺序播放；同一用户排队中的同款连送合并数量，当前演出不会被新礼物截断。最多等待 100 段，超过容量时继续普通感谢和榜单统计，不继续堆积动画。暂停和原生端重连保留后台中的队列、送礼者和进度；重启后台不重放旧礼物。

感谢语音仍在播放时保留谢幕动作和送礼者卡片，读完再进入下一份礼物；单段最多展示30秒，避免异常语音长期占用场景。暂停时冻结等待时间。

奶蛙路径在“互动视频”设置中配置。视频在独立线程预加载，最长 8 秒，保留透明通道和声音；没有有效文件时使用热茶，解码失败时仍有热茶动作与送礼者名片。礼物视频跟随演出进度，避免拖到下一位送礼者的表演中。完整持物动作使用已有的分层骨架，原始立绘模式只能显示静态人物与道具。

## 送礼者专属展示

礼物名片现在带头像光环与流光，区分“今日初次心意”和“再次陪伴”，显示收到本笔礼物时的今日累计件数。每种礼物有对应赠言，结束时显示陪伴致谢。数据只来自真实收到的礼物；同一平台消息的重传不重复累计，不同消息的同款连送正常计数。首次与再次陪伴的开场语可在内置话术修改。

常驻钓鱼的礼物撒网同样显示送礼者头像、昵称与专属祝福，结果卡展示其全部鱼获。关闭头像气泡仍保留专属头像；头像不可用时显示昵称首字，超长昵称自动省略。

## 自主生活流程

“设置 → 冷场互动”中开启“普通场景久无互动时自主活动”。默认安静90秒后开始：会客厅轮换沙发小憩、窗边观景、喝茶和散步，露台有远眺、小憩和散步，云台有远眺、散步与小跑。

人物先移动到互动位置，到达后才改变动作和镜头，停留默认18秒、上下浮动20%，随后起身回到中央，再等待下一轮。开启自主换景后，同一场景至少停留300秒，再在空闲时走到门口，按会客厅→云台→露台循环。安静时间、停留时间、换景间隔、互动区行为、换景和配套话术均可设置。

真实观众发言、点赞或送礼优先；自动安排的小憩会结束，观众主动要求的睡觉不会被自动叫醒。新的人物/场景指令接管后，旧自动流程不再覆盖它。直播暂停和礼物演出冻结场景时钟，常驻钓鱼沿用自己的小动作和换钓点规则。自主话术在“内置话术 → 自主活动”修改，点歌期间默认不插入自主聊天。

## 梦话设置

“设置 → 冷场互动 → 睡着后说梦话”默认开启。人物到达沙发并睡下约 8 秒后，可以说“发醒醒就能叫醒我”等梦话，默认间隔 45 秒，可改为 15～3600 秒。梦话不改变睡姿；醒来、开演礼物、开始钓鱼或暂停直播会取消不适用的梦话。

钓鱼、礼物和梦话台词在“设置 → 内置话术”对应分类修改，支持预览和恢复默认。捕获台词支持 `{name}`、`{fish}`、`{value}`，礼物台词支持 `{name}`、`{gift}`。及时提示按状态使用完整台词，普通 AI 对话也会收到睡眠、钓鱼、礼物队列和可用礼物效果目录。

## 循环背景 BGM

在“设置 → 背景 BGM”选择本地音频，或直接输入路径，界面会自动勾选循环播放。确认音量大于0，点击“保存并生效”。仍可手动取消勾选来关闭。支持中文路径，以及本机媒体后端可解码的 MP3 / WAV / OGG / FLAC / M4A / AAC 等格式。背景 BGM 是独立音频通道，不进入点歌榜或触发自动点歌。

“当前播放状态”显示已保存配置的真实运行情况：未开启、缺文件、点歌暂歇、随直播暂停、静音、音量为0或播放失败。修复文件后可点“重试已保存的 BGM”；修改配置要先保存。文件存在不等于开关已经开启。OBS 的 MJPEG 媒体源只有视频，需要另加本工作台的应用程序音频捕获。

- 默认音量 0.2；说话或播放互动视频时压低至设定比例，默认 25%，结束后平滑恢复。
- 点歌实际播放期间暂歇，歌曲停止、结束或播放失败后从原位置继续。空歌单的旧播放标记不会压住 BGM。
- 直播暂停、后台断线时暂停；恢复连接后继续。静音按钮同时作用于背景 BGM。
- 文件丢失或无法解码会提示，不会不停重试或切换观众点的歌曲。重新选择文件后保存即可。

## 本地验证

在根目录运行 `python -m pytest tests -q`。旧备份位于 logs 中，直接扫描整个目录会把备份测试一起收集，所以应指定 tests。

`python tools/check_live_features.py` 使用临时配置和统计库、独立端口、关闭采集与付费 AI / 语音，验证常驻钓鱼、实名点赞冠军、礼物排队、暂停重连、睡眠梦话和循环 BGM。`--screens-only` 只生成各阶段的横竖屏截图。报告和截图位于 `logs/live-features-check`。真实抖音事件字段、音色和外放效果仍需实际直播验证。
