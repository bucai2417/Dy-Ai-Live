## 今日统计

后台将数据保存到运行配置同目录下的 live-stats.sqlite3，默认路径是 data/live-stats.sqlite3。按电脑本地日期划分记录，同一天重启自动恢复；过午夜进入新一天，旧日报仍保留在数据库中。

保存内容包括输入和输出 Token、模型与离线调用次数、回应数、弹幕和入场计数、礼物次数与累计价值、完整送礼用户榜、点赞累计、下一档阈值和轮播顺序。恢复完整礼物榜后仍只显示排名前十的头像气泡，排名较低的用户后续送礼仍可超过并替换上榜用户。

金额按当前设置的输入和输出 Token 单价重新计算。当前在线人数与本次运行时长是实时状态，重启后重新获取。旧语音、歌曲队列、视频和已触发的点赞整活不会重播。

「清空本场弹幕和歌单」只清空待处理内容、播放队列和整活队列，不删除今天的 Token、礼物榜和点赞统计。切换接入来源也保留今日累计。

工作台预览上方显示最近保存时间。后台按一秒周期在线程中保存，使用 SQLite 事务提交，正常退出时再保存最后一次。强制结束进程或断电可能丢失最后一轮尚未提交的数据；不影响已提交记录。写入失败会显示错误并重试。数据库或今日记录损坏时保留原文件、显示读取失败并停止覆盖；可关闭后台后备份并移走该文件，再重新启动创建新库。

旧版本从未存盘且已经丢失的数据无法自动找回。本次上线后的数据会开始保留。

## 每次换装

| 弹幕或手动选项 | 行为 |
| --- | --- |
| 换衣服、换装、换个造型、下一套 | 按水手服 → 雨衣 → 星空礼服 → 水手服循环，每次都换成不同的一套 |
| 换个配饰 | 皇冠 → 墨镜 → 蝴蝶结循环，保留衣服 |
| 穿上雨衣、穿水手服、穿上星空礼服 | 固定选择指定服装；重复指定同一服装会保持该服装 |
| 戴墨镜、戴皇冠、戴蝴蝶结 | 固定选择配饰，不换掉衣服 |
| 恢复原装 | 水手服并移除配饰 |

换衣服会保留送礼获得的墨镜；服装与配饰仍保存到运行配置中。真正换衣需要在设置中启用分层骨架，原始立绘模式会提示开启骨架。

AI 意图分类与离线短句识别都使用“下一套服装”的动态意图，执行时读取当前服装决定下一套。不同弹幕即使文字相同，也会逐次切换。明确指定某件衣服不会被强制改成另一套。
