# 原生骨架与换装

2026-11-07：第一阶段已实现，无需浏览器或额外动画服务。

## 使用

重新启动工作台，在「设置 → 人物与互动」选择：

- 人物显示方式：分层骨架，或原始立绘。
- 人物服装：蓝海水手服、柠檬雨衣、星空礼服。
- 人物配饰：墨镜、皇冠、蝴蝶结，或恢复原装。
- 骨架辅助线：显示关节与连接，默认关闭；开启后会进入实际输出画面。

互动面板可以播放动作、切换装扮，下面显示当前服装和配饰。弹幕支持“挥手”“伸个懒腰”“摆尾巴”“穿上雨衣”“穿上星空礼服”“换衣服”。泛指换衣服时选择雨衣；“恢复原装”恢复水手服并去掉配饰。原始立绘模式不接受换衣指令，会提示开启分层骨架。

衣服与配饰使用不同状态。换衣保留墨镜；墨镜礼物保留当前衣服。通过互动命令变更会保存到运行配置，重连和重启恢复。暂停保留动作姿势和骨架时间，恢复后接着播放。切换动作有约 0.22 秒的关节过渡，口型独立更新。

## 已实现的骨架

14 个关节：根节点、躯干、头部、左右发束、左右上臂、左右前臂、左右手腕、尾部、左右尾鳍。13 个基础图层加每套 4 个服装图层，共 25 张预加载图片。关节为父子关系，例如前臂旋转会带动手腕，袖子绑定上臂。

挥手会抬臂并转动手腕；伸懒腰抬双臂；比心动作双手合拢并配合爱心特效；害羞举手遮脸；舞蹈、摆尾、点头和冷场动作驱动对应关节。手部目前是手套轮廓，没有逐根手指骨骼。普通场景与骑车、蛛丝、火箭共用同一人物渲染器，蛛丝连接手部锚点。

## 素材与扩展

- assets/avatars/deepy/model.json：画布、关节、图层与服装映射。
- assets/avatars/deepy/base/：基础身体、头发、四肢和鲸尾。
- assets/avatars/deepy/skins/：三套上衣、裙片、左右袖子。
- app/native/avatar/rig.py：模型校验、关节姿势、过渡、图层绘制和锚点。
- tools/build_avatar.py：可重建素材的源码，使用项目现有立绘和本地矢量绘图，未调用付费生图服务。

素材全部使用统一的 983×1407 设计坐标；实际 PNG 裁去透明边缘，JSON offset 记录图片相对关节的偏移。替换画师素材时同步校准这个偏移，不能只把新图缩放到相同文件尺寸。

构建命令：

~~~powershell
python tools/build_avatar.py
~~~

会覆盖内置模型图片。精修前请先保存自己的版本；也可使用 --output 指定另一个输出目录。新增服装除加入图片和 model.json 外，还需在 SKINS 注册标识并添加意图映射，目前没有任意模型上传功能。

模型加载会检查层级循环、父节点、坐标、文件路径、图片和完整服装槽位。所有服装预先加载，切换时不读磁盘。模型异常则使用原始立绘并显示回退提示。正式运行时不要把 assets/avatars/deepy 当成旧文件删除。

## 当前边界

这版是可用的二维刚性分层骨架，保留原脸部、发色与鲸尾，身体和服装采用程序绘制，画风细节与原立绘不同。它不是 Cubism / Spine 编辑工程，也没有软网格、布料模拟、三维转身或手指细节。大角度遮挡和手势仍可用更精细的美术图层逐步改善。角色没有双腿，骑车保留“鱼尾驱动”的场景表现。

原生测试使用隔离配置，不连接真实直播间、在线 AI 或 TTS；测试报告和截图写入 logs/native-check。新增回归测试见 tests/test_avatar_rig.py。
