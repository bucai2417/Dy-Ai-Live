## 仅留本机的内容

.env、data/ 的配置/登录态/统计/缓存/互动视频、music/ 曲库、logs/ 日志与截图、archive/ 旧代码和设计稿、缓存、node_modules、dist/ 产物不进入公开仓库。data/README.md 和 music/README.md 保留配置说明。

外部 webmssdk.js、web/vendor/*.js 和 web/models/haru/ 在原开发目录保留，由 .gitattributes 的 export-ignore 排除在导出包之外。新公开仓库的 .gitignore 也忽略这些文件，避免意外提交。不要对原开发仓库直接执行公开推送，它的旧历史可能保存过这些材料。

## 导出与公开仓库

在项目根目录运行：

~~~powershell
git status --short
python tools/export_source.py
~~~

导出器仅使用已提交的版本，默认 HEAD，输出 dist/Deepy-source-提交号.zip。它不包含 .git 历史，尊重 export-ignore，并拒绝敏感路径及未排除的外部组件。BAT 转为 UTF-8 无 BOM、CRLF；已有输出不会覆盖。未提交修改不会进入包中。

首次公开发布使用该包在独立目录建立干净的 Git 仓库，以 main 为主分支，创建 v1.0.0 标签和 GitHub Release。后续版本应在已有公开仓库历史上提交新快照，保留已发布标签，不强制覆盖远程。原开发仓库保留本机历史，两者不要混推。

## 运行与验证

此版本提供源码，没有独立 EXE。安装 requirements-desktop.txt 后运行 python -m app --desktop；python -m app --version 输出版本号。不使用浏览器采集时，在设置选择 bridge 或 mock；直连缺少可选 SDK/Node.js 时会回退 CDP 浏览器采集，原生画面显示仍独立运行。

在干净解压目录安装 requirements-dev.txt 后运行 python -m pytest tests -q。可选签名组件未配置时，仅跳过依赖真实签名子进程的测试，仍验证缺组件检测、协议参数与其他功能。然后运行 tools/check_native.py 验证原生画面、音视频及最小化持续绘制；两者顺序执行，避免争用 CPU。

视频测试使用 tools/sample_media.py 在临时目录生成透明方块和测试音频，无需私人奶蛙视频。不应把真实 .env、data/runtime.json、音乐或互动视频复制到公开源码中。
