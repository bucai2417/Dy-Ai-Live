# 三维场景与点赞环游

原生直播工作台包含海风会客厅、星海露台、云上天境景观云台和 16 秒流光环游。无需浏览器或额外三维引擎，使用现有 Python / PySide6 绘制线程生成直播画面，窗口最小化时仍继续输出。

## 开始使用

更新后完整关闭并重新启动工作台和后台，进入「场景导演」。新配置默认启用海风会客厅；关闭「启用原生三维场景」即可回到经典舞台。此开关会保存；导演面板里的移动、镜头、天气和场景切换只作用于本场，后台重启时采用「直播设置 → 三维场景」保存的默认值。

「直播控制 → 点赞达标整活」选择「深蓝环游 · 流光泡泡」，点击「预览整活」可直接观看。默认轮播顺序为环游、骑车、蛛丝、火箭；之前设置了固定整活的用户仍沿用固定模式，可在「直播设置 → 点赞整活」选择环游或轮播。默认每新增 100 赞触发一次，阈值可修改。

## 场景与天气

- 海风会客厅：木地板、地毯、沙发、落地灯、书柜、茶桌和绿植，雨雪只从窗外及小屋外侧可见。
- 星海露台：木平台、栏杆、灯串、休息沙发、望远镜和绿植，支持户外雨雪。
- 云上天境：景观会馆、格栅屋顶、花园、喷泉水池、环形观光车道、观景台、路灯、栏杆和停车位。进入会馆与室内场景相连。
- 天气：晴空、听雨、飘雪、星夜。雨雪和星光粒子可单独关闭，夜间会改变场景色调。
- 视角：全景、左右侧面、俯视、近景；还可以逐步旋转、抬高、降低、拉近、拉远。

场景采用实际三维坐标、透视投影、按深度排序的几何面和面光照。人物是放在三维场景里的二维骨架立绘，会随距离缩放、被前方家具遮挡，始终面向观众；不是可查看背面的三维人物模型。画风是低多边形微缩布景，暂不包含真实光线追踪、布料物理或天气音效。

## 弹幕示例

| 想做什么 | 可以发送 |
| --- | --- |
| 移动人物 | 小鱼往左游、向右走两步、向前游、后退一下 |
| 去指定位置 | 小鱼去窗边吧、去沙发旁、回到中央 |
| 停止移动 | 停止移动、停在这里 |
| 调整镜头 | 拉近镜头、拉远镜头、镜头向右转、抬高镜头 |
| 切换视角 | 切换俯视、切换全景、切换人物特写 |
| 切换天气 | 下点雨、让这里下雪吧、切换晴天、换成星夜 |
| 切换场景 | 切换场景、换个场景、去云台、去露台、回家、出门 |
| 跑步和驾驶 | 跑步、跑一圈、散步、开车、开车兜风、停车、下车 |
| 室内交互 | 去沙发、去沙发睡觉、去窗边看风景、喝杯茶、起床 |
| 室外交互 | 去花园、去停车位、看看云海、去观景台 |
| 点播完整环游 | 游来游去、游一圈、全屏游动 |
| 其它整活 | 骑自行车、荡蛛丝、坐火箭 |
| 停止与重做 | 停止动作、停止整活、别跳了、再来一次、重复刚才的动作 |
| 状态与帮助 | 你在干嘛、你现在在睡觉吗、人物状态、你在哪里、你能做什么 |

已配置的 AI 也可以理解同义表达；未配置 AI 时使用本地明确短句识别。聊天「今天下雨了」、否定「不要下雪」、转述和假设不作为场景指令。AI 输出只能选预设动作，不能执行任意代码、文件路径或坐标。

弹幕场景控制默认间隔 2 秒，可单独关闭或调整间隔；全局关闭自动人物互动也会关闭弹幕场景控制。手动导演按钮不受弹幕间隔限制。重复内容仍按独立弹幕识别，连续操作仅受设置的间隔限制。停止移动、停车、下车和起床可打断当前行为，不受场景间隔限制；这些明确短句和“停止动作”直接处理，不等待语音回复队列。

“切换场景”“换个场景”按会客厅 → 云上天境 → 星海露台 → 会客厅轮换。“出门”进入云台，“回家”始终返回会客厅。“云上天镜”和“云上天境”均可识别。散步沿场景路线活动 24 秒。

人物移动限制在家具之间的活动区域；镜头角度和距离有上限，不能无限旋转或穿过人物。新的移动和镜头指令从当前过渡位置继续，停止指令会停在当前所在位置。

「场景导演 → 场景互动」可手动测试所有行为。跑步沿场景路线巡游 15 秒，双臂交替摆动、尾鳍摆动并带脚下扬尘。角色仍是鱼尾骨架，使用摆尾与跃动表现跑步，没有凭空增加双腿。

开车会自动进入云台，沿环路巡游 18 秒后停靠停车位，车辆使用三维几何并随路径转向。“停车”“别开了”或驾驶中的“停止移动”会就地停车并保留车头方向，人物仍在驾驶位。“下车”让人物移动到车旁，车辆保留在云台，继续走动时仍可看见；没有上车时会明确提示。室内、露台不能驶入车辆。

到达沙发后人物平滑躺卧、闭眼小憩；到达窗边后镜头推进并展开带窗框的窗外景观特写；茶桌触发举杯姿态与热气；观景台触发远眺。方向移动接近这些地点也会触发。发送“起床”返回中央，发送“停止移动”就地结束互动；也可直接发送下一个地点或动作。

进屋、出门通过场景切换连接室内外，当前不是无加载门洞的连续建筑漫游。手动镜头操作可退出自动特写，不改变人物正在进行的行为。

## AI 状态感知与执行反馈

「场景导演」新增“AI 当前知道”状态区，面板可见时每两秒刷新，显示场景、人物行为、动作剩余时间及最近一次弹幕操作结果。读取状态不调用付费模型。也可以发送“你在干嘛”得到当前状态回复。

每次意图识别和聊天生成都会读取最新状态：

- 场景、天气、镜头、位置、目的地、行进时间及到达后的行为。
- 去沙发途中与已经躺下睡觉、驾驶与停车仍在车内、下车过程与下车完成。
- 正在播放的骨架动作、效果、剩余时间，以及点赞整活和待播数量。
- 当前服装、配饰、正在播放与下一首歌曲，以及直播暂停状态。
- 当前设置允许的操作目录和最近操作成功或失败的实际结果。

动作以服务端时间记录，并同步给原生画面。暂停冻结动作时间，恢复后继续；工作台重新连接时可恢复尚未结束的短动作。冷场自动动作和自动话题会避让睡眠、驾驶、走动和已有短动作。礼物、手动和明确弹幕互动仍按原优先级工作，状态中会区分场景行为与叠加动作。

“停止动作”会清除短动作、当前与待播整活，并在允许弹幕控制场景时就地停止场景行为；驾驶中则停车留在车内。音乐和今日统计保留。“再来一次”重放最近一次成功接收的场景、动作、换装、视频或整活请求，仍执行权限与冷却检查。失败请求不会覆盖可重做记录；清场后记录清空。“停一下”沿用原有暂停音乐含义，请用“停止动作”停止人物。

明确口令由本地直接执行，复杂同义表达交给已配置的 AI 识别。AI 只可从能力目录中选择预设指令，执行端再次检查当前状态；例如未上车时不能成功执行“下车”。普通聊天回复本身不执行动作，也不能临时生成任意新动画。当前支持每条弹幕的一个主要意图，尚未实现连续多步骤任务规划。

开发排查可读取只读接口 `GET /api/ai/context`，得到与模型请求一致的能力和状态数据；接口不包含 API 密钥、视频路径或音乐播放地址。

## 兼容原有互动

16 秒环游包含平滑转向、远近缩放、双臂划水、鲸尾与尾鳍摆动、流光尾迹和气泡。活动区域避开音乐、Token、榜单、弹幕和字幕。横竖屏自动采用各自的舞台范围。

环游期间服装和配饰继续生效，送墨镜仍会戴上墨镜，语音口型继续工作；比心、挥手等动作可叠加，倒立和缩小等改变游动人物的姿态。礼物气泡降低透明度，让环游主体更清晰；奶蛙视频显示在动作上方。冷场动作不会插入点赞整活。

普通挥手、倒立、跳舞、比心、音乐律动以及礼物特效也使用场景中的人物位置。骑车、蛛丝和火箭作为舞台前方的表演叠层播放，结束后回到场景位置。整活过程中更改的人物位置和镜头在后台继续平滑更新，结束时采用更新后的状态。

暂停直播会冻结点赞动画、人物移动、镜头过渡、雨雪星光和动画时钟；恢复后从暂停位置继续。画面客户端重连会重新获取场景、天气、移动及镜头进度。后台重启采用保存的开播默认设置。

## 性能与扩展

几何体和各天气的布景只创建一次；镜头及人物深度不变时复用已绘制的布景图层。雨雪粒子数量固定，不随弹幕累积。沿用独立渲染线程和 MJPEG 输出，不依赖浏览器后台定时器。

- app/world.py：服务端场景状态、命令白名单、移动和镜头插值、暂停与重连快照。
- app/world_navigation.py：活动边界、地点锚点、网格寻路、喷泉和建筑避让、环形巡游路线。
- app/native/world_scene.py：三维几何、透视相机、天气、人物定位和前后遮挡。
- app/native/stunts.py：16 秒环游路径、泡泡尾迹和原有点赞表演。
- app/native/avatar/rig.py：划水、摆尾及叠加互动的骨架角度。

增加家具时需要同时维护地点锚点、活动边界和障碍范围。普通移动使用二维地面网格寻路并合并可直达路段，车辆使用专用环路；不是完整的三维碰撞物理引擎。后续若替换为真正三维角色，需要补充带骨架、材质和动画的 glTF / VRM 等资产，并接入能绘制这些资产的原生三维渲染器。

## 本地验证

~~~powershell
python -m pip install -r requirements-dev.txt
python -m pytest tests -q
python tools/check_world.py
python tools/check_native.py
~~~

check_world.py 离线生成横竖屏场景截图、天气总览、16 秒环游 GIF 和渲染耗时报告，保存在 logs/world-check。check_native.py 使用临时配置验证原生窗口、控制按钮、音视频、暂停、最小化输出及重连；不改写真实配置，不调用真实弹幕或在线 AI。

原生窗口验收覆盖切歌、暂停恢复、场景导演、驾驶、连续换装、10 个礼物气泡、透明视频和重连。详细报告分别位于 logs/native-check/结果.json 与 logs/world-check/结果.json。帧率取决于分辨率和同时启用的音视频效果；离线渲染耗时不包含直播音视频、窗口预览和输出编码的完整负载。

2026-11-07 本轮验收：539 项自动测试通过。原生云台驾驶、雪天、音乐和互动同时运行时，最小化四秒测得横屏 109 帧（27.25 FPS）、竖屏 120 帧（30 FPS）。这是本机短时测量，不保证所有电脑或全部组合都恒定 30 FPS。
