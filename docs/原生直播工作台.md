## 2026-11-07：排行气泡、装扮与奶蛙视频

头像气泡最多 10 个，默认按累计礼物价值排序，也可在「设置 → 音乐与画面 → 头像气泡排行依据」改成礼物累计数量。榜外观众的贡献继续累计，超过榜内观众后自动替换；同分保持先上榜的顺序。排行与头像气泡即时同步，重连可恢复当前榜单。按用户 ID 区分同名用户；没有 ID 时按昵称合并。榜单按日重置，同日重启和清空本场保留当天统计。

发送「奶蛙」「奶娃」「小奶蛙」或包含这些词的弹幕，会立即播放带声音的透明视频，不需要配置在线 AI。已将指定的 cutout.webm 复制到 data/interaction-media/奶蛙.webm，保留原文件。视频约 1.83 秒，使用透明画面叠加，不会出现黑色矩形背景。重复发送会逐次排队，最多等待 10 次，队列满时工作台提示；同一条消息的重传不重复排队。「不要播放奶蛙」不会触发。

工作台有「播放奶蛙视频」按钮；在「设置 → 互动视频」可更换本地路径、触发词、音量和显示大小。短片限制为 8 秒以内、64 MB 以内。视频首次加载在后台解码，之后使用帧缓存；默认缓存约 35 MB。支持带透明通道的 VP9 WebM，视频声音由原生播放器输出并自动压低音乐。全局静音包含视频声音；直播暂停冻结视频并暂停声音，恢复后继续；清场清除播放和待播队列。

新增「倒立」「转个圈」「变小」动作，以及「戴皇冠」「戴墨镜」「换衣服」「恢复原装」装扮指令。当前装扮为皇冠、墨镜、蝴蝶结配饰叠加；「换衣服」切换为蝴蝶结装扮，不会更换角色本体服装。真正的服装替换需要额外服装图层或支持换装的模型素材。

「画面联动」开关已实现：新歌开始时跳舞，礼物榜首更替时庆祝并短暂戴上皇冠。触发依据是本直播画面已知的音乐和排行状态；尚未读取外部游戏窗口、桌面截图或进行 OCR / 视觉识别。当前玩法见[文档导航](README.md)。

## 弹幕理解与礼物气泡

弹幕可交给已配置的模型判断意图。可以说「播放晴天」「能放周杰伦的晴天吗」「耳朵想听稻香了，安排一下」「给大家鞠个躬」，无需固定点歌格式。支持点歌、切歌、暂停 / 继续音乐、查询当前歌曲和 11 种人物动作，也可识别装扮和奶蛙视频请求。模型只可返回允许的操作；低置信度按聊天处理，否定表达和歌曲讨论不应触发点歌。AI 识别结果及实际歌曲查询结果会分别记录 / 反馈，不会只说成功却没有入队。

在工作台设置中配置模型地址、密钥和名称即可使用 AI 语义判断。未配置、鉴权失败、超时或返回格式错误时，自动使用本地明确指令规则；本地支持「播放晴天」「能放周杰伦的晴天吗」「跳个舞吧」等常见表达，但不能代替模型理解所有说法。识别调用有独立超时并计入模型用量，正常聊天随后仍由聊天模型回复。

同一观众重复发送、不同观众发送相同内容，都会重新处理。已移除按弹幕文字去重、同用户冷却、相同回复跳过，以及超过 30 秒自动丢弃待回复弹幕的限制。礼物会立即显示，语音按队列依次处理，不再为感谢礼物取消正在处理的聊天。仍保留敏感词 / 长度过滤、暂停清队列、采集通道对同一消息的重复投递识别及有限容量保护；点歌队列仍最多 30 首、每位观众最多占用 3 首，达到上限会回复原因。

任意礼物都会计入排行，前 10 名的头像和昵称一起在整个直播画面移动，可跨越场景、标题和信息栏，气泡互相碰撞并在画面边缘回弹。再次送礼会更新头像、昵称、累计礼物数与排名。可在「设置 → 音乐与画面」调节显示开关、人数（最多 10）、排序依据、大小、速度和边缘回弹。重连恢复榜单，不会将历史礼物再次累计。

头像通过独立异步请求下载，并使用有限缓存；绘制线程只读取解码后的图片和气泡精灵缓存。桥接支持 AvatarUrl、HeadImgUrl、AvatarThumb 等常见头像字段；接入源未提供头像或下载失败时显示昵称首字，昵称和碰撞照常工作。整个功能使用原生 Python / PySide6，不需要打开浏览器直播画面。

## 启动

- 双击「启动.bat」：使用已保存的正式配置，检查并安装缺失的桌面依赖。
- 双击「演示.bat」：新服务临时使用模拟弹幕，不修改正式接入配置。
- 双击「直播画面.bat」：与正式启动相同，可复用已有后台。
- 已有服务正在运行时，演示入口会沿用它的接入设置；要切换模拟模式，先关闭已有工作台及其服务。

命令行：

~~~bat
python -m pip install -r requirements-desktop.txt
python -m app --desktop
python -m app --desktop --width 1280 --height 720 --fps 30
python -m app --desktop --fps 20
~~~

默认渲染 720×1280、30 FPS，视频端口 18849。MJPEG 输出固定 25 FPS，与 FFmpeg mpjpeg 解封装的时间基准匹配；渲染低于 25 FPS 时复用最新帧。后台端口沿用 .env 的 PORT。需要改变视频端口时追加 --output-port 18850。单独运行 python -m app.renderer 只连接后台，不创建后台。

工作台关闭后会停止自己启动的后台；如果复用了外部已有后台，则保留已有后台。同一视频端口只允许一个工作台。

## 音乐播放器与人物互动

直播画面常驻音乐卡片，显示当前歌名、歌手、点歌人、已播时间 / 总时长、播放进度、待播数量和下一首。没有歌曲时显示点歌提示，歌曲时长未知时显示 --:--，暂停、缓冲、断线和关闭音乐有各自的状态提示。长歌名会省略，避免压住其他内容。

进度使用本机 QMediaPlayer 实际音频位置；暂停或缓冲时不会凭墙上时间继续前进。切歌清除上一首的播放位置，下一首来自后台队列的第一项，礼物插队后会同步改变。播放时唱片和小音柱轻微运动，小音柱是播放状态装饰，不是音频频谱测量。控制面板也显示当前 / 下一首和进度，并保留播放、暂停、下一首和点歌操作。

人物支持 11 种动作：招呼摇摆、鞠躬感谢、开心跳跃、摇摆跳舞、害羞脸红、惊喜反应、开心大笑、点头回应、倒立、转圈、变小。人物动作区选择后点「播放动作」即可直接展示，不需要生成测试礼物或调用 AI。

自动触发包括：

| 互动 | 原生画面反应 |
|---|---|
| 弹幕「跳个舞」「跳舞」「扭一个」 | 摇摆跳舞和彩纸 |
| 弹幕「可爱」「漂亮」「好看」 | 歪头、脸红与爱心 |
| 弹幕「哈哈」「笑死」 | 大笑摇摆与气泡 |
| 弹幕「666」「厉害」「太强」 | 开心跳跃与星光 |
| 打招呼、进场、关注 | 招呼摇摆 |
| 普通礼物 / 高价值礼物 | 鞠躬感谢 / 惊喜反应；后台规则可指定特效 |
| 播放音乐 | 小幅随播放时间摇摆，暂停时停止 |

动作带淡入淡出和优先级，单次粒子数量有上限，不建立无限动作队列。手动动作优先；连续点击有 0.6 秒保护。直播暂停会清除动作与特效，恢复后不补播。

在「接入设置 → 人设 / AI / 语音 / 画面设置 → 音乐与画面」可切换「直播画面显示音乐播放器」「自动响应弹幕 / 礼物动作」「人物爱心 / 星光 / 彩纸特效」「播放音乐时轻轻摇摆」。关闭自动响应后，仍可以手动播放动作。

这些动作使用现有立绘进行整体位移、旋转、缩放，搭配眼嘴贴片和粒子绘制；不包含独立的手臂、头发或尾巴骨骼。截图保存在 logs/native-check/音乐与互动-竖屏.png 与 音乐与互动-横屏.png。

## OBS 配置

1. 添加「媒体源」，取消「本地文件」。
2. 输入工作台「画面输出」提供的 URL，默认 http://127.0.0.1:18849/live.mjpeg 。
3. 输入格式填 mpjpeg，并关闭「源不可见时关闭文件」。按实际负载调整网络缓冲。
4. 使用应用程序音频捕获选择本工作台，或捕获桌面音频。只采集一份声音。
5. 画布采用与视频相同的横竖比例，再按已有流程交给直播伴侣。

视频源只含画面。工作台、纯净窗口的最小化不会停止独立渲染线程；OBS 应接上述视频流，窗口捕获的最小化行为不在本方案保证范围内。系统休眠、关机或关闭工作台后不会继续输出。

## 稳定性实现

- 独立线程绘制 QImage；GUI 重绘与后台画面生成分离。
- 只保留最新帧，慢视频客户端不会造成帧队列无限增长。
- JPEG 编码与帧发布使用不同锁，多客户端复用编码结果。
- 渲染和音频出错在工作台状态栏显示；连接中断后自动重连。
- 重连读取当前歌单和休息状态，不重放历史语音；音频位置按后台状态校准。
- 全局直播暂停会取消在途 AI、欢迎语和人工播报，避免恢复后突然播放过时内容。
- 所有新增源码、配置写入、状态文件、日志与启动器按 UTF-8 处理。

## 墨镜礼物、Token 费用与歌曲限制（2026-11-07）

- 实际收到名称含「墨镜」的礼物后，人物立即戴上墨镜，不等待 AI 回复。重复赠送仍触发；自动互动关闭或直播暂停时不换装。墨镜保留到下一次主动换装，榜首变化不会临时替换为皇冠。
- 打开「直播设置 → Token 用量与费用」，可单独开关画面显示，并分别填写输入、输出价格，单位为元 / 百万 Token，支持四位小数。保存立即重算显示金额。这个开关独立于顶部统计图标。横竖屏都在顶部紧凑显示总用量和估费，关闭时不改变场景位置。
- 用量包含意图分类、模型回复、模型兼容性探测和连接测试。接口缺失某项 usage 时只估算缺失项，并标记「估算」；真实的 0 保留为 0。费用始终是按当前单价估算的参考值，变更价格会重算当前累计量，不是服务商账单。统计范围是当日用量，同日重启恢复，跨天归零。
- 「直播设置 → 歌曲限制」可填写额外禁播歌名、别名、歌手或专辑关键词。内置国歌、军歌、红歌等分类词和一组常见歌名；这是本直播的内容规则，不是法律分类结论。检查原始点歌内容和解析后的歌名、歌手、可用专辑 / 别名 / 分类信息；本地歌曲检查文件及目录名称。链接和文件路径点歌不接受，需填写歌名。
- AI 自动点歌只使用「已确认自动点歌歌单」，每行填写「歌名 | 歌手」，歌手可选但建议填写。默认歌单为空，暂不自动点歌；填写后只选择该列表，解析结果还需匹配歌名和填写的歌手。禁播规则优先，手动把禁播歌加入列表也不会播放。
- 弹幕、手动点歌、礼物点歌、自动点歌、本地曲库和切歌 / 恢复播放共用规则。设置改变后清理不符合规则的待播歌曲，并停止不符合规则的当前歌曲；每次播放前再次检查。明确请求演唱相关歌曲的弹幕会回复换歌提示。

歌曲检查依赖文本信息，无法识别所有音译、改名、同名翻唱、错误元数据或音频实际内容；自动歌单请先试听确认，可继续补充禁播关键词。更改本地音频内容但不改文件名也不能通过文字规则识别。

新增回归测试位于 tests/test_gift_tokens_policy.py。原生端到端脚本同时检查墨镜礼物、中文设置保存、Token 金额热更新和显示开关；截图保存在 logs/native-check/Token价格设置.png 和 Token计费与墨镜礼物-横屏.png / 竖屏.png。
