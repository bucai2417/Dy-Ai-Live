# Dy-Ai-Live 1.0.0 · 大肥鱼 / 深蓝 Deepy

Python + PySide6 桌面工作台，负责直播画面、互动控制、语音与音乐播放。默认直播显示不使用浏览器，独立绘制线程持续生成画面，支持横竖屏和暂停直播。

**版本：1.0.0 · 许可：PolyForm Noncommercial 1.0.0（源码可见，禁止商业用途）**。许可边界见 [中文说明](docs/非商业使用许可说明.md) 和 [第三方说明](THIRD_PARTY_NOTICES.md)，功能变更见 [更新记录](CHANGELOG.md)。

v1.0.0 Release 提供 Python 源码。main 分支已配置 Windows 自动构建，可在 GitHub Actions 下载免安装 EXE 目录包；未来版本标签通过检查后会自动上传对应 Release，详见 [Windows 自动构建](docs/Windows自动构建.md)。

**第一次使用请阅读 [详细用户教程](docs/用户使用教程.md)**：从 EXE 下载、源码启动、AI / 语音配置，到弹幕接入、OBS 画面与声音、钓鱼和礼物玩法、命令速查、备份升级及故障排查。新构建的 Windows 包也会附带同一份「使用说明.md」。

## 启动

Windows，Python 3.10 或更新版本。首次使用在项目根目录执行：

~~~powershell
python -m pip install -r requirements-desktop.txt
Copy-Item .env.example .env
python -m app --desktop
~~~

已有 .env 时跳过复制；个人设置和密钥保存在 .env、data/runtime.json 中，不进入 Git。桌面设置优先读取已保存的运行配置，缺省项使用代码默认值及 .env 兜底。

| 入口 | 用途 |
| --- | --- |
| 启动.bat | 正式启动，检查桌面依赖，首次缺失时尝试安装 |
| 直播画面.bat | 同一原生工作台入口，可复用已启动的后台 |
| 演示.bat | 临时模拟弹幕，不改写已保存的接入配置 |
| 桥接服务.bat | 为外部弹幕助手提供 HTTP 回调入口 |
| 自检.bat | 运行项目回归检查，需要开发依赖 |

演示模式只替换弹幕源；配置了在线 AI 或语音时仍会使用这些服务。已有后台运行时会复用其配置，切换到完整模拟模式前先退出原工作台。

命令行也可使用：

~~~powershell
python -m app --desktop --demo
python -m app --desktop --width 1280 --height 720 --fps 30
python -m app
~~~

最后一条只启动后台。单独运行原生画面可使用 python -m app.renderer，它需要已有后台。

## 直播功能

- 弹幕接入：模拟、外部助手桥接、浏览器 CDP 采集；直连接口需额外配置合法取得的签名组件和 Node.js，公开源码不附带该外部组件。
- 互动：自然语言意图判断、动作与表情、礼物响应、墨镜配饰、最多 10 个排行头像在全屏移动碰撞。
- 内容：当前 / 下一首音乐、点歌与禁播规则、透明互动视频、点赞达标 16 秒环游 / 骑车 / 蛛丝摆荡 / 火箭动画。
- 场景：原生三维会客厅、露台和云台景观建筑；15 秒跑步、18 秒驾驶、沙发睡觉、窗边观景和茶桌互动，支持晴雨雪夜与镜头控制。
- 钓鱼：44种水族与12件趣味奇物，点赞、拉钩和礼物协力；常驻支持自动昼夜、礼物撒网与实名庆祝、投饵、加油护线、松线捣蛋、三处钓点、冷场小动作、主动邀请、久无收获自动换点、今日图鉴和花式跳水。管理员或授权榜单前三可发“进入常驻钓鱼模式 / 退出常驻钓鱼模式”，鱼竿和撒网收获均累计今日排行。字幕采用轻量描边与两行分页。
- 礼物演出：热茶 / 奶蛙、花束、巨型棒棒糖、墨镜等完整骨架演出，送礼者头像昵称随场展示，依次播放后恢复原活动。
- 梦话与背景音乐：睡觉时主动邀请观众叫醒自己；本地 BGM 循环、音量设置、语音压低背景音、点歌时自动暂歇。
- 连续换装：每次发送“换衣服 / 换装 / 下一套”轮换一套服装，“换个配饰”单独轮换配饰。
- 今日数据：Token、回应、弹幕计数、礼物榜、钓鱼榜和点赞进度自动存盘，同一天重启继续累计；清空弹幕和歌单不会清掉今日统计。
- 节奏：完整语音分段播放、可编辑内置话术、冷场聊天与动作、按当前能力轮换的玩法邀请、暂停 / 恢复直播。
- 画面：横竖屏大场景、顶部图标统计、原生纯净输出窗口、Token 用量和按设置单价估算的费用。
- 滚动公告：底部循环展示玩法介绍，设置中编辑文本、速度和开关，适配横竖屏。

这些功能的操作说明见 [原生直播工作台](docs/原生直播工作台.md)、[三维场景与点赞环游](docs/三维场景与点赞环游.md)、[钓鱼玩法与滚动公告](docs/钓鱼玩法与滚动公告.md) 和 [文档导航](docs/README.md)。真实弹幕依赖所选接入通道；浏览器采集与原生画面绘制是独立流程。

## OBS 接入

默认后台端口为 8848，视频输出端口为 18849。OBS 添加「媒体源」，取消「本地文件」，输入：

~~~text
http://127.0.0.1:18849/live.mjpeg
~~~

该地址输出画面，声音由原生音频播放器播放，需在 OBS 配置相应音频采集。工作台默认渲染目标为 30 FPS，MJPEG 输出为 25 FPS；机器负载会影响实际帧率。横竖屏切换后同步调整 OBS 画布与源尺寸。详细设置见 [原生输出说明](docs/原生直播工作台.md)。

## 模型动作与真正换装

当前原生 Deepy 默认使用分层骨架：14 个父子关节、独立手臂 / 手腕 / 头部 / 发束 / 鲸尾，以及水手服、柠檬雨衣、星空礼服三套可替换衣服。现有眼嘴贴片继续驱动表情和语音口型；原生人物不依赖 Haru 网页示例。

在“设置 → 人物与互动”选择人物模式、衣服和配饰；互动面板也能直接切换。弹幕可发送“挥手”“伸个懒腰”“摆尾巴”“穿上雨衣”“穿上星空礼服”。衣服和墨镜等配饰独立保存，重连和重启恢复；暂停会保留当前姿势。

第一版是现有立绘裁片与程序绘制服装组合，采用刚性图层关节，不是 Live2D 网格变形；可以切回原始立绘。角色目前没有双腿，真正踩踏自行车仍需专用素材。使用、素材扩展和边界见 [原生骨架与换装](docs/原生骨架与换装.md)，长期路线见 [模型骨架与换装实施方案](docs/模型骨架与换装实施方案.md)。

## 验证与开发

~~~powershell
python -m pip install -r requirements-dev.txt
$env:PYTHONUTF8='1'
python -m pytest tests -q
python -m compileall -q app tools/check_native.py
python tools/check_native.py
~~~

最后一项使用本地测试服务和素材，打开原生窗口并在 logs/native-check 写入截图与报告，不用浏览器展示；它会检查播放回执、横竖屏、最小化持续渲染和 MJPEG 解码。完整测试与原生检查请顺序运行，避免 CPU 争用影响帧率测量。自动检查不替代真实房间、在线模型 / TTS 和长时间直播验证。

文本使用 UTF-8；BAT 必须为 UTF-8 无 BOM、CRLF 换行。已通过 .editorconfig 和 .gitattributes 固定编辑及检出规则。整理与归档清单见 [项目整理记录](docs/项目整理记录.md)。
