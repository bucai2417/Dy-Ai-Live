# 本机运行数据

本目录由程序按需创建。除本说明外，所有内容由 .gitignore 排除，不进入 Git。

- runtime.json：桌面设置、话术、模型配置；可能包含 API 密钥。
- browser-profile/：弹幕采集使用的浏览器登录态和缓存。
- interaction-media/：本地互动视频，例如奶蛙.webm。
- native-display-*.json：各视频端口的横竖屏选择。
- native-renderer-*：工作台状态、锁等运行文件。
- 其他缓存：语音、图片、临时媒体等，按需生成。

整理项目不会清空这些文件。新检出项目使用代码默认值和 .env；恢复个人配置或奶蛙视频，需要从自己的本地备份复制，并在设置中核对视频路径。Git 克隆不会带上现有的登录态、密钥或个人媒体。
